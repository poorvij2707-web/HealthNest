# HealthNest – Design System

## 1. Product Overview
HealthNest is a Personal Health Manager that helps users organise their health records, medications, doctor appointments and daily wellness activities in one place.

## 2. Colour Palette

| Element | Colour | Hex Code |
|---|---|---|
| Primary | Blue | #2563EB |
| Background | Light Blue-Gray | #F5F8FC |
| Main Text | Dark Navy | #172033 |
| Secondary Text | Gray | #718096 |
| Cards | White | #FFFFFF |
| Borders | Light Gray | #E5EAF0 |

## 3. Typography
- Font family: Arial / Sans-serif
- Main headings: Bold
- Section headings: Semi-bold
- Body text: Regular
- Buttons: Medium weight

## 4. Layout
- Sidebar navigation on the left.
- Main content displayed on the right.
- Dashboard uses a two-column card grid.
- Pages use consistent padding and spacing.

## 5. Components
- Sidebar navigation
- Dashboard cards
- Input fields
- Buttons
- Health record lists
- Medication lists
- Appointment lists
- Wellness tracking controls

## 6. Buttons and Interactions
- Blue buttons for primary actions.
- Hover effect changes the button to a darker blue.
- Cards have rounded corners.
- Users can add and delete records.
- Users can pause or activate medicines.
- Users can mark appointments as completed.
- Users can track water, sleep and exercise.

## 7. Design Principles
- Simple and clean interface.
- Easy navigation.
- Consistent colours and typography.
- Clear information hierarchy.
- User-friendly interactions.
